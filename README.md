# Fisioterapia · Comunidad de Madrid

Cuaderno personal para la Orden 2119/2023, acceso libre a personal **laboral**, Titulado Medio, especialidad Fisioterapia (Grupo II, nivel 7, Área D). Las ampliaciones alcanzan 155 plazas, 11 reservadas para discapacidad. No corresponde al proceso de personal estatutario del SERMAS.

## Contenido y alcance

- 50 temas con enunciados del programa oficial: 14 generales y 36 específicos.
- 1.200 fichas conceptuales (24 por tema) y 2.400 variantes de pregunta, en dos sentidos de reconocimiento.
- 50 tests de 20 preguntas por tema: 2.500 pruebas distintas que **reutilizan el banco**. No son 2.500 bancos independientes ni 50 exámenes oficiales completos por tema.
- 50 mixtos de 80 preguntas + 5 reservas: 10 generales, 70 específicas y 5 reservas específicas. Mixto 50 reservado como final.
- Corrección con aciertos − errores/3; blancos sin penalización. Las reservas se muestran por separado. Las netas de práctica no representan una nota oficial ni un criterio de aprobado.
- Progreso local, recuperación de la prueba en curso y copia/restauración JSON; exportación CSV.
- Fuentes BOCM/BOE, recursos clínicos complementarios y prompt de NotebookLM para cada tema.

Las fichas y preguntas son material propio elaborado con ayuda de IA, de reconocimiento conceptual, no un temario completo ni una colección de preguntas oficiales. No sustituyen los supuestos prácticos ni una revisión docente especializada. Las referencias de ampliación no acreditan individualmente cada pregunta. La presencia de técnicas en el programa no implica eficacia clínica demostrada.

## Uso

Publicación estática, sin instalación ni servicios de terceros para los tests. Abrir la URL HTTPS en Safari/Chrome, no la vista previa de un HTML adjunto. Los datos permanecen en el navegador; no hay sincronización automática entre dispositivos. La biblioteca enlaza servicios externos sujetos a su disponibilidad.

Para revisar localmente: `python3 -m http.server 8765`, y abrir `http://localhost:8765`.

Para comprobar la integridad: `python3 verify.py` (Python 3.9 o posterior).

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). `.nojekyll` mantiene el sitio estático. No requiere claves ni credenciales en los archivos.
